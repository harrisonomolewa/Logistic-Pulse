# Logistics Pulse: Fleet, Safety & Cost Analytics

A 4-page Power BI dashboard built on a 14-table logistics dataset.

![Logistics Pulse Dashboard](Combined%20Dashboard.jpeg)

## Pages
- **Executive Summary:** revenue, miles, revenue per mile, MPG, loads
- **Delivery Performance:** on-time %, detention time, late deliveries
- **Drivers & Safety:** incidents, at-fault %, claims, cargo damage
- **Fuel & Fleet Cost:** fuel spend, cost per mile, maintenance by type and truck age

## Tools
Power BI, DAX, Power Query
